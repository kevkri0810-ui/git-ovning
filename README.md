# Git-övning

Det här är en enkel övningsmapp för att träna Git och GitHub.

## Filer
- `index.html` – en enkel webbsida
- `style.css` – sidans utseende
- `main.js` – lite JavaScript
- `anteckningar.txt` – en textfil att ändra under övningen
- `.gitignore` – exempel på filer som Git ska ignorera

Testa att ändra en fil, kontrollera med `git status`, lägg till ändringen med
`git add` och spara den med `git commit`.
